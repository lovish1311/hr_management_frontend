================================================================================
DART SPREAD OPERATOR (...) AND COLLECTION-IF EXPLAINED IN LAYMAN'S TERMS
================================================================================

Let's break down this syntax:
    if (condition) ...[
       widget1,
       widget2,
    ]

--------------------------------------------------------------------------------
1. THE EVERYDAY ANALOGY (Shopping Bags)
--------------------------------------------------------------------------------
Imagine you are packing a single grocery bag (a List of items):

   Main Bag = [ Apples, Bread, Milk ]

Now, imagine you have a smaller separate bag on the counter containing snacks:
   Snack Bag = [ Chips, Cookies ]

SCENARIO A (Without the dots '...'):
If you do:
   Main Bag = [ Apples, Bread, Milk, Snack Bag ]
What happened? 
You literally put a BAG INSIDE A BAG! 
The result looks like this:
   [ Apples, Bread, Milk, [Chips, Cookies] ]   <-- A list inside a list!
In Flutter, Column(children: <Widget>[ ... ]) expects a flat list of Widgets.
It does NOT want a List inside a List! It will throw an error: 
"List<Widget> cannot contain another List<Widget>".

SCENARIO B (With the three dots '...'):
The three dots '...' is called the SPREAD OPERATOR.
Think of '...' as "UNPACKING" or "DUMPING" the contents of the bag out.
If you do:
   Main Bag = [ Apples, Bread, Milk, ...Snack Bag ]
The dots open the small snack bag and dump Chips and Cookies directly into 
the main bag:
   [ Apples, Bread, Milk, Chips, Cookies ]    <-- Flat, clean list!


--------------------------------------------------------------------------------
2. ADDING THE "IF": (Collection-If)
--------------------------------------------------------------------------------
Now add the IF condition:
"If I have a party tonight, unpack the snack bag into my main bag."

   if (isPartyTonight) ...[
       Chips,
       Cookies,
   ]

- If `isPartyTonight` is TRUE:
  It creates the list [Chips, Cookies], unpacks them (...), and drops Chips 
  and Cookies into the main list as separate items.

- If `isPartyTonight` is FALSE:
  Nothing gets dumped into the main list. It skips both items cleanly.


--------------------------------------------------------------------------------
3. LOOK AT YOUR EXACT LOGIN PAGE CODE
--------------------------------------------------------------------------------
In your `login_page.dart`:

Column(
  children: [
    // Item 1: Title
    const Text('HR Management'),

    // Item 2: Subtitle
    const Text('Sign in to access your portal'),

    // Item 3: Mode Switcher Banner
    _buildModeSwitcher(),

    // =====================================================================
    // HERE IS THE CODE:
    // =====================================================================
    if (!_isProductionMode) ...[
      // Inside this temporary sub-list, we have 3 items:
      Text('DEMO CREDENTIAL PRESETS'),     // sub-item A
      const SizedBox(height: 8),           // sub-item B
      Row(children: [ ... ]),              // sub-item C
    ],
    // =====================================================================

    // Item 5: Error Banner (if error exists)
    if (_errorMessage != null) ...[
      Container(...),
      const SizedBox(height: 20),
    ],

    // Item 6: Email Field
    TextFormField(...),
  ],
)

Why do we need `...[` here?
Because inside `Column(children: [ ... ])`, Flutter expects individual items 
comma-separated.
If you have MULTIPLE items that you only want to show when demo mode is on:
1. `[ Text(...), SizedBox(...), Row(...) ]` groups those 3 widgets together.
2. `...` unpacks them so they become 3 normal siblings in the Column's children.
3. `if (!_isProductionMode)` decides whether this entire block exists or not.


--------------------------------------------------------------------------------
4. WHAT IF YOU HAVE AN "ELSE"?
--------------------------------------------------------------------------------
Dart also allows `else` with the spread operator:

Column(
  children: [
    if (!_isProductionMode) ...[
      // Shown when in DEMO mode:
      Text('Demo Mode Active'),
      Row(children: [ /* Demo Buttons */ ]),
    ] else ...[
      // Shown when in PRODUCTION mode:
      Text('Production Mode - Live System'),
      Icon(Icons.shield_outlined),
    ],

    // Rest of the page continues here:
    TextFormField(...),
  ],
)


--------------------------------------------------------------------------------
5. SUMMARY IN ONE SENTENCE
--------------------------------------------------------------------------------
- `[ a, b, c ]` creates a mini-group of widgets.
- `...` removes the outer brackets and dumps `a, b, c` directly into the parent.
- `if (condition)` only does the dump if the condition is true.
